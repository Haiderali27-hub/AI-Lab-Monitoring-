\subsection{System Testing}\label{subsec:system_tests}

System tests run complete exam flows through the web panel in a browser. In the same test, a student-client simulator sends the same requests as the desktop client, so a student action can be followed to the invigilator's screen.

System testing runs one complete exam day through the web panel in a browser, with a student-client simulator in the same test. Table~\ref{tab:st_1} follows the order of an exam day, from the first sign-in to the audit log, and every row passed in the final run.
