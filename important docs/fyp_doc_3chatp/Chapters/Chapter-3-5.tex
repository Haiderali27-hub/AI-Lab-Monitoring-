\section{Managerial Process Plan}

Even with only three people involved, establishing guidelines for coordinated, supervised, and managed change for SmartExam's twelve interrelated modules is critical \cite{spp1}. These processes serve to minimize overlap, prevent documentation drift, and manage unexpected project scope expansion.

\subsection{Communication and Coordination}

The project team will convene at the beginning and conclusion of each sprint. A meeting scheduled at the start of each sprint establishes primary objectives for each four-week phase, while a review meeting at the end of the sprint assesses what was deployed, what was not, and the reasons for either outcome. Regular daily communication is conducted using asynchronous check-ins \cite{scrum1}. Any blockages not addressed within 24 hours trigger a team discussion for proactive resolution. Documentation efforts run in parallel with module development, preventing the FYP report from diverging from the developed prototype by incorporating updates into the same sprint \cite{spp1}.

\subsection{Review and Feedback Integration}

Supervisor feedback is treated as the highest priority input. All identified SRS gaps, design inconsistencies, or scope drifts will be addressed in the following sprint without deferment to the end of the project \cite{agile1}. Modules are subject to individual testing before integration, checking functionality against specifications \cite{agile1}, ensuring clean execution and compilation with no bugs \cite{spp1}, and requiring at least one unit test to execute successfully \cite{agile1}.

\subsection{Change Management}

While expecting change is characteristic of Agile, not all proposed adjustments can be incorporated. Evaluation of any proposed change is based on three factors: its improvement to the overall academic content, its inclusion fitting within the sprint budget, and its potential to destabilize existing modules \cite{agile1}. Approved changes enter the next sprint's backlog, while those failing these criteria are added to the future-work record for subsequent consideration \cite{spp1}.
