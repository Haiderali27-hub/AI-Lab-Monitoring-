Implement a Singly Linked List 'reverse' function in Python that handles an empty list or a list with a single node.

def reverse_list(head):
    prev = None
    current = head
    while current:
        next_node = current.next
        current.next = prev
        prev = current
        current = next_node
    return prev # Correct implementation

Explain the time complexity of searching for an element in a balanced Binary Search Tree (BST).

The time complexity for searching in a balanced Binary Search Tree is O(log n). This is because with each comparison, the search space is effectively halved, similar to binary search in an array. If the tree becomes unbalanced, the complexity can degrade to O(n).
